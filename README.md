## Projects

### 🛠 [Jamf Counter](https://github.com/RobinJanss/Jamfcounter-demoprojekt) — Automation / API
Device fleet reporting across **87 school MDM instances**: parallel API queries, a **hand-built xlsx writer** (native Excel charts, no libraries) and a cloud-synced instance list. Built to replace hours of manual work at my FSJ – now it's a double-click.
`python3 jamf_counter.py --demo` runs it without credentials.

### 🌡 Smart Filament Cabinet — Embedded Systems
An IKEA cabinet turned into a climate-controlled storage for 3D-printing filament: **five ESP32 nodes** on an ESP-NOW mesh, PTC heater control, three-layer safety concept with a fail-loud alarm. *(Write-up coming to GitHub soon.)*

### 🚚 Delivery Rush — Game Dev
A 3D arcade delivery game in **Godot 4**: procedural city generation, arcade vehicle physics. *(Playable web demo coming soon.)*
